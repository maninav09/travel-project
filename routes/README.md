# Routes

Express routers live here. Each file owns one API area.

- `authAPI.js`: signup, signin, password reset, and profile upload flows
- `busAPI.js`: bus search results and fallback data
- `cabAPI.js`: cab search results and fallback data
- `enhancementsAPI.js`: saved preferences and shareable itinerary helpers
- `exploreRoute.js`: endpoints for hotels, famous places, hidden gems, and food corners
- `routeAPI.js`: trip planning, saved routes, durations, and AI trip details
- `trainAPI.js`: train search results and fallback data
