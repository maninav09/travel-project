Overview

Smart travel planning for city-to-city journeys

Routes-connect is a full-stack travel planning platform designed to simplify trip preparation. It brings route comparison, destination discovery, weather updates, AI assistance, safety tools, and travel support into one experience.

Problem

Travel planning usually gets split across many apps and websites, which makes the process slower, more confusing, and less organized.

Solution

Routes-connect centralizes the most useful planning features into a single platform so users can move from search to decision more smoothly.

Core Features

Features that make the platform practical

Travel Planning

  • Route planning between cities
  • Train, bus, cab, and flight-style comparison
  • Route map and weather snapshot

Destination Discovery

  • Hotels, restaurants, food corners, and famous places
  • Hidden gems and destination discovery
  • Tourist-place cards with photos

Smart Tools

  • AI trip planning support
  • Smart budget splitter
  • Safety dashboard and shareable trip links

User Experience

  • Login and signup flow
  • Profile image upload
  • Previous trip review and history
Technology Stack

A full-stack build with real integrations

Frontend

HTML5, CSS3, JavaScript, and Progressive Web App support through `manifest.webmanifest` and `sw.js`.

Backend

Node.js, Express.js, REST API architecture, Dotenv, Multer, Bcryptjs, and CORS for a structured server-side application.

Database

MongoDB with Mongoose for schema-based storage when database mode is enabled.

Third-Party Services

OpenAI, Pexels, Geoapify, Google Maps, Open-Meteo, and EmailJS for AI, location, weather, and communication features.

Project Setup

How to run the project correctly

Install dependencies with `npm install`, create the environment file from `.env.example`, add the required API keys and configuration, and then start the server with `npm start`.

Important Variables

  • `PORT`
  • `USE_MONGO`
  • `MONGO_URI`
  • `GOOGLE_MAPS_API_KEY`
  • `OPENAI_API_KEY`

Scripts

  • `npm start` for the server
  • `npm test` for automated tests
  • `npm run seed` and `npm run seed:trains` for train data
