# Public

This folder contains the static frontend that the Express server serves directly.

- `index.html`: landing page
- `services.html`: services overview page
- `route.html`: route results, map, reviews, AI plan, and saved trips
- `login.html`: login and signup experience
- `about.html`: about page
- `404.html`: fallback page for unknown routes
- `script.js`: landing page interactions
- `route.js`: route page interactions and API calls
- `login.js`: authentication modal and profile image flow
- `home-logic.js`: reusable home-page helper logic used in tests
- `theme.js`: light and dark theme toggle logic
- `style.css`: landing and shared page styles
- `route.css`: route page styles
- `login.css`: login page styles
- `sw.js`: service worker cache setup
- `manifest.webmanifest`: installable web app metadata
- `img/`: static images bundled with the app
- `uploads/`: user-uploaded profile and place images
